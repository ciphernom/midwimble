**Dimebag**, after Pantera's "Walk", is released alongside midstate's v6.0.0
"Anselmo". It is a hard fork. From block **86,400**, midwimble's proof of work
is **Midstate Walk**, the one midstate takes at its block 420,000.

**Every node must upgrade before block 86,400**, which is expected around
mid-December 2026, a few hours before midstate's switch. A node on an earlier
release rejects the first Walk block.

## What changes

- **The Walk:** blocks from 86,400 carry a Midstate Walk proof, natively and
  merged. The Walk code is shared with midstate (`src/core/walk.rs`) and
  reproduces its golden vectors.
- **Sync:** blocks below 86,400 keep the BLAKE3 chain, so syncing from genesis
  works as before.
- **Difficulty:** at the switch the target eases 8× (`WALK_TARGET_SHIFT = 3`),
  and ASERT takes over from there.
- **Midstate's switch is mirrored:** relayed midstate headers and anchor
  evidence from midstate block 420,000 on are checked as Walk proofs, with
  midstate's 8× reset. `MIDSTATE_WALK_ACTIVATION_HEIGHT` and
  `MIDSTATE_WALK_TARGET_SHIFT` must match midstate v6.0.0.

## Mining

- **Merged mining pauses between the two switches.** A merged block counts
  only if it carries the proof of work its height asks for. From midwimble's
  block 86,400 until midstate reaches 420,000, a few hours later, the merge
  pool mines midstate alone and bonded miners carry midwimble. `merge-mine` and
  the pool resume merging by themselves once both chains take the Walk.
- **Algorithm by height:** `midwimble node --mine-to`, `merge-mine`, and the
  pool and its spot checks all follow the height.
- **GPU backend:** `--backend gpu` mines the Walk on the CPU, because the GPU
  kernel is the BLAKE3 chain's.
- **Templates:** `/mining/template` and `/merge/job` carry `pow`
  (`"blake3-chain"` or `"walk"`).
- **Hardware:** a Raspberry Pi 5 is the smallest machine that mines the Walk
  well, because it has AES instructions. Pi 3 and Pi 4 builds still run full
  nodes.
- **Mining in the browser:** the web wallet's Mine page (`wallet/#/mine`)
  mines through the merge-mining pool for the wallet's own address, one tap
  from the welcome screen, with a countdown to the Walk and an earnings
  estimate. `/merge/job` now says what the block mints (`reward`), which the
  pool passes on for that estimate. Pools need midstate v6.0.0 to take
  miners who give only a midwimble address.

## Also

- Header sync requires consecutive heights, and checks each header's proof of
  work with the algorithm for its height.
- Orphans near either switch are accepted with either algorithm until they can
  be placed.
