A fix for the Linux x86-64 download, and the node's side of mining in the
browser. Consensus is v1.2-DIMEBAG's: from block **86,400** the proof of work
is Midstate Walk, and every node must run v1.2-DIMEBAG or later before then.

## The Linux x86-64 binary starts again

v1.2-DIMEBAG's and v1.1.2-WONKABURN's Linux x86-64 binaries were built on
GitHub's `ubuntu-latest`, which moved to Ubuntu 26.04, and need glibc 2.43. On
Debian 13, Ubuntu 24.04 and anything older they stop with "version
`GLIBC_2.43' not found". This one is built on Ubuntu 24.04 and needs glibc
2.39 at most, and the build now stops if a Linux binary needs anything newer.
The ARM64 (Raspberry Pi) binaries were built on Ubuntu 24.04 all along and
were fine.

## Mining in the browser

- **The web wallet mines:** its Mine page (`wallet/#/mine`) mines through the
  merge-mining pool for the wallet's own address, one tap from the welcome
  screen, with a countdown to the Walk and an earnings estimate. Pools need
  midstate v6.0.1 to take miners who give only a midwimble address.
- **`/merge/job` says what the block mints** (`reward`), which the pool
  passes on for that estimate.
